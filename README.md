# 🚀 Featured Project — WandalMT

### Full Stack Web Application

**WandalMT** is my most advanced web development project, built using modern JavaScript and TypeScript technologies.

The application combines a responsive React frontend with a Node.js and Express backend, MongoDB database management, secure authentication, online payment processing, and cloud storage integration.

The project follows a **client-server architecture**, separating frontend presentation from backend business logic and data management.

### ✨ Key Features

- 🔐 **Authentication & Authorization** — JWT-based authentication and secure password hashing with bcryptjs.
- 💳 **Online Payments** — integration with Stripe.
- ☁️ **Cloud Storage** — file management using Backblaze B2 and S3-compatible APIs.
- 🖼️ **Image Processing** — image optimization and processing with Sharp.
- 🌍 **Internationalization** — multilingual interface using i18next.
- 📧 **Email Integration** — automated email communication through Mailgun.
- ⚙️ **Backend Automation** — scheduled tasks using Node-cron.
- 💾 **Database Management** — MongoDB, Mongoose, and backup utilities.
- 🛡️ **Application Security** — input validation, CORS configuration, and Google reCAPTCHA.
- 🧪 **Testing** — Jest and React Testing Library.
- 📱 **Responsive Design** — React and Tailwind CSS.

# ⚙️ Local Setup

### Prerequisites

- Node.js (LTS recommended)
- npm

### Clone the repository

```bash
git clone https://github.com/Monika464/Portfolio.git
```

### Navigate to the project

```bash
cd Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
